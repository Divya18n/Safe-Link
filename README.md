# 🔗 Safe-Link – AI Powered URL Security Scanner

![Node.js](https://img.shields.io/badge/Node.js-Backend-green)
![TypeScript](https://img.shields.io/badge/TypeScript-Language-blue)
![Security](https://img.shields.io/badge/Security-URL%20Scanner-red)
![License](https://img.shields.io/badge/License-MIT-yellow)

**Safe-Link** is an AI-powered web application designed to detect **phishing, spam, and malicious URLs** using multi-level threat analysis and real-time risk scoring.

The system analyzes URLs using multiple techniques to help users identify potentially dangerous links before visiting them.

---

# 🚀 Features

* 🔍 Scan URLs for phishing and malware
* 🛡 Multi-level threat analysis
* ⚡ Real-time risk scoring
* 🌐 Integration with **Google Safe Browsing API**
* 📊 Detailed security analysis reports
* 🎨 Modern UI built with **Tailwind CSS**
* ⚙ Full-stack architecture (client + server)

---

# 🔄 How It Works

1️⃣ User enters a URL into the scanner
2️⃣ System analyzes the link using multiple security checks
3️⃣ Google Safe Browsing API checks for known threats
4️⃣ Risk score is generated
5️⃣ Security report is displayed to the user
